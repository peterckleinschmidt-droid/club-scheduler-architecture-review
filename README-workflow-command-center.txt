Scheduler Workflow Command Center Package

Files included:
- app/admin/workflow/page.tsx

This replaces the workflow page with a more status-oriented command center.
It expects the Google health check files from scheduler-healthcheck-files.zip to already be installed.

After installing:
1. Run npm run build
2. Restart npm run dev if needed
3. Open /admin/workflow
4. Test the Google health check card and workflow statuses
